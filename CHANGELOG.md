# Changelog

Notable changes to the nightly report and tooling. Newest first.

## Unreleased
- Schedule-aware add/drop: swaps are valued day by day from when the move takes effect. A drop with an unplayed game today and an add who doesn't play today gives "drop after X's game tonight" (with the add's first game) instead of a do-now gain that throws away tonight's points (e.g. Sat 10/31 +Podziemski / −Kuminga showed +10; it is +45 after tonight). Tipped games and waiver claims count from the next open day. Moves show a by-day gain; Opportunity watch shows each player's next game and games left.
- The overview sentences are generated by the tool from the report's numbers; the routine replies verbatim (a hand-written overview once got a result backwards).
- Fix: the flex pool (players added in the last 7 days) never saw anything older than today, because ESPN returns one scoring period of transactions per request. Recent adds now look back 7 periods.
- Fix: the 2am nightly saw yesterday's roster (ESPN's default view rolls over later), missing evening adds/drops. The roster is now requested for the report date's scoring period; the matchup week comes from our calendar.
- Compact nightly: one Matchup grid (night, today, week, change since yesterday); News limited to significant items; IR watch one line; look-ahead off by default; shorter footnotes; 3 opportunities; one League table + one summary line replaces Season picture and Power rankings.
- Accuracy data capture (M6, part 1): snapshots v2, daily actuals files, 200-day retention, `fbgm accuracy` status. The review itself comes after ~14 scored days.
- Opportunity watch (M5): free agents with a minutes surge or a star teammate out, backed by a backtest tool. Informational only.
- Schedule look-ahead (M4): games per player and lineup FP vs each opponent for the next 3 weeks; moves show next-3-week games.
- Season picture (M3): standings, playoff odds, must-win flag and Godfather watch in the nightly.
- Pre-tip lineup check (M2): `fbgm pretip` and a routine that runs before tonight's games lock.
- Monitoring (M1): section failures are contained; silent data failures are counted; data checks; health banner and
  Health section; `fbgm watchdog` and a watchdog routine; `FBGM ERROR` line on fatal failures; nightly routine persists
  state before replying.
- Foundations (M0): report code split into `fbgm/report.py` and `fbgm/fmt.py`; unit test suite under `tests/`; CI (lint +
  tests) on PRs; `tools/golden_nightly.py` for before/after report comparisons.

## 2026-10-28
- Nightly report: projected vs actual for last night (team and player level), yesterday's week projection and win
  chance vs today's. Snapshots persist on the `nightly-state` branch.
- IR watch: return timeline tracking, with alerts when a return is near, when its estimate moves, or when it disappears.
